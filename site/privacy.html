Privacy Policy

Effective date: September 20, 2026

Short version: Inbox Cleaner for Gmail accesses Gmail only after you grant permission, processes message information locally in your browser, does not operate a backend that receives your inbox data, and never deletes or trashes messages without your explicit confirmation.

1. Scope

This Privacy Policy explains how the Inbox Cleaner for Gmail Chrome extension (the “Extension”) accesses, uses, stores, and protects information. The Extension’s single purpose is to help users review and clean low-value Gmail messages.

2. Information the Extension accesses

After you connect a Google account, the Extension uses the Gmail API to access the minimum information required for its features:

  • Your Gmail account email address, to show which account is connected and separate local cache data by account.
  • Inbox message identifiers and thread identifiers.
  • Message metadata including sender, recipient, subject, date, Gmail labels, and the standard List-Unsubscribe header when available.
  • Gmail-provided message snippets, used for local classification.
  • The ability to modify Gmail labels so messages you explicitly select can be moved from Inbox to Trash.

The Extension does not request message bodies or attachments. It does not access contacts, calendars, Drive files, browser history, or unrelated website activity.

3. How information is used

Message information is used only to provide the Extension’s user-facing inbox-cleanup features: listing messages, grouping them by sender, applying deterministic local scoring rules, displaying KEEP / REVIEW / CLEAN suggestions, showing unsubscribe links supplied by senders, and moving user-selected messages to Trash after confirmation.

The Extension does not use artificial intelligence or remote classification services. It does not use Gmail data for advertising, credit decisions, surveillance, profiling, or any unrelated purpose.

4. Local processing and storage

The Extension has no developer-operated backend. Gmail data travels directly between Google’s Gmail API and the Extension running in your Chrome browser over HTTPS.

The Extension stores settings and recent scan information in chrome.storage.local on your device. Recent message metadata and snippets may be cached locally for up to 24 hours to restore the latest scan and reduce Gmail API quota usage. Cache entries are limited in number. OAuth access tokens are managed by Chrome Identity and are not written to Extension storage.

5. Sharing and sale of data

The Extension does not send Gmail data to the developer or to third parties. It does not sell, rent, disclose, or transfer Gmail data for advertising or marketing. Humans working on the Extension cannot read your inbox because the developer does not receive it.

If you choose an Unsubscribe action, the Extension opens the unsubscribe URL provided by that email sender in a new browser tab. Your interaction with that sender’s website is governed by the sender’s own privacy practices.

6. Google API and Chrome Web Store Limited Use

Inbox Cleaner for Gmail’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The Extension’s use of user data also complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. User data is used only to provide or improve the Extension’s single, disclosed purpose.

7. Your controls and deletion

  • You can disconnect Gmail from the Extension at any time. Disconnecting clears cached authentication tokens and account-specific local scan data.
  • You can remove the Extension from Chrome to delete its local Extension storage.
  • You can revoke account access at any time from your Google Account’s third-party access settings.
  • Messages moved to Gmail Trash remain subject to Gmail’s own retention and recovery behavior.

8. Security

The Extension uses Google OAuth through Chrome Identity and communicates with Gmail only through HTTPS Gmail API endpoints. Permissions are limited to identity, local Extension storage, and Gmail API access required for reviewing and moving messages to Trash.

9. Children

The Extension is not directed to children under 13 and is not intended for use where parental consent is required by applicable law.

10. Changes to this policy

If the Extension’s data practices change, this page and any required in-product disclosures will be updated before the change applies. The effective date above identifies the latest version.

11. Contact

Questions or privacy requests can be sent to hakan@akins.app.
